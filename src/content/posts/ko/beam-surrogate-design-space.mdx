## 형상 하나의 예측에서 여러 형상의 탐색으로

3D 형상을 넣었을 때 성능을 빠르고 신뢰성 있게 예측할 수 있다면 무엇을 할 수 있을까요? 기준 형상을 조금씩 바꾼 후보를 수천 개 만들고, 어떤 방향의 변화가 유리한지 한눈에 살펴볼 수 있습니다. 하나의 예측값이 **설계공간의 성능 지도**가 되는 것입니다.

이번 글에서는 이 흐름을 실제로 실행해 보겠습니다.

**형상 정의 → 정답 데이터 생성 → 모델 학습·검증 → 3,721개 후보 추론 → 성능 지도 → 유망 후보의 정답 재평가**

결과부터 보면, 같은 질량의 외팔보에서 폭을 20 mm에서 10 mm로 줄이고 높이를 20 mm에서 40 mm로 늘렸을 때 해석식 처짐이 **{format(beam.improvement_pct, 1)}% 감소**했습니다. 그런데 테스트 평균 상대오차가 {format(beam.test.mape_pct, 3)}%인 모델도 설계공간의 한 모서리에서는 {format(beam.grid.max_relative_error_pct, 2)}% 틀렸습니다. 성능 지도를 읽는 일과 예측을 검증하는 일을 함께 다뤄야 하는 이유입니다.

## 무엇을 바꾸고, 무엇을 고정할까?

한쪽 끝을 벽에 고정한 직사각형 단면의 **3D 외팔보**를 생각해 봅시다. 자유단에는 아래 방향 힘이 작용합니다. 길이 방향을 $x$, 단면의 가로 방향을 $y$, 높이 방향을 $z$라고 두면 형상은 길이 $L$, 폭 $b$, 높이 $h$인 직육면체입니다.

<div className="table-wrap" role="region" tabIndex={0} aria-label="설계 변수와 고정 조건">

| 구분 | 설정 | 의미 |
|:--|:--|:--|
| 설계 변수 $b$ | 10–40 mm | 단면의 폭, $y$ 방향 |
| 설계 변수 $h$ | 10–40 mm | 하중 방향에 대응하는 단면 높이, $z$ 방향 |
| 길이 $L$ | 500 mm | 모든 형상에서 고정 |
| 탄성계수 $E$ | 70 GPa | 균일한 선형 탄성 재료로 가정 |
| 밀도 $\rho$ | 2,700 kg/m³ | 질량 계산에 사용 |
| 끝단 하중 $F$ | 10 N | 자유단의 아래 방향 집중하중, 비틀림 없음 |
| 경계조건 | $x=0$ 완전 고정 | 고정단의 변위와 회전이 0 |
| 예측할 값 | 끝단 처짐의 크기 $\delta$ (mm) | **작을수록 좋음** |
| 설계 제약 | 질량 $m \leq 0.540$ kg | 재료 사용량의 상한 |

</div>

기준 형상은 $(b,h)=(20,20)$ mm입니다. 폭과 높이는 모두 양수이고 길이는 고정이므로 설정한 범위 안에서 퇴화하지 않는 직육면체를 만들 수 있습니다. 질량 제한을 넘는 형상도 기하학적으로는 유효합니다. 다만 이번 설계의 채택 대상에서 제외합니다.

여기서 모델의 입력은 메시나 포인트 클라우드가 아닙니다. 정확히는 **형상을 정의하는 설계 변수 $(b,h)$를 입력으로 받는 모델**입니다. 같은 폭과 높이라도 구멍이 있거나 단면이 길이에 따라 달라지는 형상은 이 두 변수로 표현할 수 없습니다.

질량 제한이 없다면 두 치수를 모두 크게 만드는 방향으로 끝날 것입니다. 제한이 있으면 폭을 늘릴 때 높이를 얼마나 포기해야 하는지, 같은 재료를 어느 방향에 배치하는 편이 유리한지 비교해야 합니다.

## 해석식으로 정답 데이터 만들기

Euler–Bernoulli 보 이론에서 이 하중 조건의 끝단 처짐 크기는 다음과 같습니다. 자유단의 처짐식은 MIT OCW의 Solid Mechanics 자료 2쪽<Cite id="mit-beam" refs={frontmatter.references} />에서도 확인할 수 있습니다.

$$
I = \frac{bh^3}{12}, \qquad
\delta = \frac{FL^3}{3EI}
       = \frac{4FL^3}{Ebh^3}, \qquad
m = \rho Lbh.
$$

$I$는 하중에 의한 굽힘 축에 대한 단면 2차 모멘트입니다. 단면의 높이가 세제곱으로 들어간다는 점을 기억해 두세요. 나중에 성능 지도의 방향을 설명해 줍니다.

계산에서는 길이를 m, 힘을 N, 탄성계수를 Pa로 통일합니다. 이때 $I$의 단위는 m⁴, 처짐은 m가 됩니다. 저장할 때만 처짐을 mm로 바꿉니다. 핵심 계산은 다음과 같습니다.

```python
def truth(x):
    # x의 각 행: [폭 mm, 높이 mm]
    b, h = np.asarray(x, dtype=float).T * 1e-3
    inertia = b * h**3 / 12
    delta_m = 10.0 * 0.5**3 / (3 * 70e9 * inertia)
    mass_kg = 2700.0 * 0.5 * b * h
    return delta_m * 1e3, mass_kg
```

이 실험의 ‘정답’은 **선택한 이론 안의 해석식 정답**입니다. 실측값이나 3D 유한요소 해석 결과는 아닙니다. 균일한 직선 보, 작은 변형과 작은 회전, 선형 탄성 거동을 가정하고 전단 변형·자중·고정단의 국부 변형·소성·좌굴은 계산하지 않습니다. 특히 밀도는 비용에 해당하는 질량을 계산할 때만 쓰며, 자중을 하중에 더하지 않았습니다.

범위 내 최대 처짐은 {format(beam.sanity.max_truth_deflection_mm, 3)} mm로 길이의 {format((beam.sanity.max_deflection_length_ratio * 100), 2)}%입니다. 가장 두꺼운 형상에서 $L/h=12.5$입니다. 이것은 설정의 규모를 확인하는 수치이지 보 이론과 실제 3D 구조의 일치나 안전성을 검증한 결과는 아닙니다. 특정 알루미늄 합금의 항복강도도 지정하지 않았습니다.

## 300개 형상으로 작은 회귀 모델 학습하기

난수 시드를 `20260921`로 고정하고, $[10,40]\times[10,40]$ mm 영역에서 폭과 높이를 각각 균등분포로 뽑아 300개의 형상을 만듭니다. 정답에는 인위적인 잡음을 넣지 않습니다. 데이터를 섞어 다음처럼 나눕니다.

<div className="table-wrap" role="region" tabIndex={0} aria-label="데이터 분할">

| 데이터 | 개수 | 사용처 |
|:--|--:|:--|
| 학습 | {beam.split.train} | 입력 표준화 통계와 모델 계수 학습 |
| 검증 | {beam.split.validation} | 미리 정한 9개 설정 중 모델 선택 |
| 테스트 | {beam.split.test} | 선택 완료 후 미사용 형상의 성능 평가 |
| 별도 탐색 격자 | {beam.grid.n} | 최종 모델로 후보 비교, 이후 정답으로 지도 감사 |

</div>

모델은 **RBF 커널 릿지 회귀**입니다. 설계 변수 두 개에서 처짐으로 이어지는 매끄러운 비선형 관계를 작은 데이터로 학습하기에 적당하고, GPU나 복잡한 신경망 구조가 필요하지 않습니다. 커널은 표준화된 설계 변수 사이의 거리를 이용하며, 가까운 형상에 대한 유사도를 바탕으로 함수를 맞춥니다. 커널과 제곱오차·정규화를 결합하는 방법은 scikit-learn 1.6의 Kernel ridge regression 문서<Cite id="sklearn-krr" refs={frontmatter.references} />를 참고했습니다.

처짐은 형상에 따라 크게 달라지므로 목표값을 $\log(\delta / 1\,\mathrm{mm})$로 변환해 학습합니다. 추론할 때 지수함수로 되돌려 mm 단위의 양수 예측을 얻습니다. 입력에 $1/(bh^3)$처럼 정답식을 직접 넣지는 않습니다. 입력은 끝까지 폭과 높이 두 개입니다.

```python
model = make_pipeline(
    StandardScaler(),
    KernelRidge(alpha=alpha, gamma=gamma, kernel="rbf"),
)
model.fit(x[train], np.log(y[train]))
validation_prediction = np.exp(model.predict(x[validation]))
```

`StandardScaler`의 평균과 표준편차는 학습 형상 180개로만 계산합니다. 검증·테스트에는 그 기준을 그대로 적용합니다. 데이터를 먼저 나누고 학습 자료로만 전처리 통계를 정하는 이유는 scikit-learn의 데이터 누수 문서<Cite id="sklearn-leakage" refs={frontmatter.references} />에 설명되어 있습니다.

정규화 강도 `alpha ∈ {1e-6, 1e-4, 1e-2}`와 RBF 계수 `gamma ∈ {0.1, 0.5, 2.0}`의 9개 조합을 비교했습니다. **검증 평균 절대 백분율 오차(MAPE)**가 가장 작은 <code>alpha={beam.model.alpha}</code>, <code>gamma={beam.model.gamma}</code>가 선택됐고, 그때 검증 MAPE는 {format(beam.validation.mape_pct, 3)}%였습니다. 비교한 모든 설정의 결과를 [실험 결과 JSON](/data/beam-surrogate/results.json)에 남겼습니다.

선택된 모델을 검증 데이터까지 합쳐 다시 학습하지 않았습니다. 테스트와 탐색 격자에도 동일한 180개 학습 형상으로 맞춘 모델을 사용합니다. 이후 격자의 정답을 보고 모델 설정을 바꾸지도 않습니다.

## 오차가 작으면 설계 순위도 믿을 수 있을까?

처음 보는 테스트 형상 60개에서 얻은 결과입니다. 여기서 상대오차는 $100\lvert\hat\delta-\delta\rvert/\delta$이고 MAPE는 그 평균입니다.

<div className="table-wrap" role="region" tabIndex={0} aria-label="테스트 평가 지표">

| 테스트 지표 | 실제 실행 결과 | 읽는 방법 |
|:--|--:|:--|
| MAE | {format(beam.test.mae_mm, 6)} mm | 처짐의 평균 절대오차 |
| RMSE | {format(beam.test.rmse_mm, 6)} mm | 큰 오차에 더 민감한 지표 |
| MAPE | {format(beam.test.mape_pct, 3)}% | 크기가 다른 처짐의 상대오차 비교 |
| 상대오차 95백분위 | {format(beam.test.p95_relative_error_pct, 3)}% | 이 값 이하에 테스트 오차의 약 95%가 위치 |
| 최대 상대오차 | {format(beam.test.max_relative_error_pct, 3)}% | 평균에 가려질 수 있는 실패 |
| $R^2$ | {format(beam.test.r2, 6)} | 테스트 값의 변동을 얼마나 설명하는가 |
| Spearman 순위 상관 | {format(beam.test.spearman, 6)} | 처짐이 작은 순서가 얼마나 보존되는가 |

</div>

Spearman 상관은 값 자체보다 순서의 일치를 측정합니다. +1은 완전한 단조 관계를 뜻합니다. 이번 테스트에서는 순서가 일치했지만, 이것이 모든 후보에서 정확한 순위를 보장한다는 뜻은 아닙니다. 지표의 정의는 SciPy의 `spearmanr` 문서<Cite id="scipy-spearman" refs={frontmatter.references} />를 참고하세요. 여기서는 상관계수를 순위 진단에 사용하며 유의성 검정을 주장하지 않습니다.

전체 격자를 정답식으로 감사해 보니 가장 큰 오차는 $(b,h)$ = ({beam.grid.worst.b_mm}, {beam.grid.worst.h_mm}) mm에서 발생했습니다. 예측은 {format(beam.grid.worst.predicted_deflection_mm, 4)} mm, 정답은 {format(beam.grid.worst.truth_deflection_mm, 4)} mm로 **{format(beam.grid.max_relative_error_pct, 2)}% 과소예측**했습니다. 테스트의 최대 오차보다도 큽니다.

## 3,721개 후보에 대한 추론과 성능 지도

폭과 높이를 각각 10 mm부터 40 mm까지 0.5 mm 간격으로 놓으면 $61\times61=3,721$개의 후보가 만들어집니다. 이는 연속 공간 전체를 계산하는 것이 아니라 **유한한 지점을 샘플링**하는 것입니다. 학습용 300개 무작위 형상과는 별도로 생성하고, 좌표가 중복되지 않음도 확인합니다.

각 후보의 처리 순서는 다음과 같습니다.

1. 학습된 모델로 처짐을 예측합니다.
2. 형상에서 질량을 직접 계산해 제한 충족 여부를 기록합니다. 질량은 예측하지 않습니다.
3. 제한을 만족한 {beam.grid.feasible_n}개 후보를 **예측 처짐**이 작은 순서로 정렬하고 상위 5개를 고정합니다.
4. 그 후보를 원래 정답 함수에 다시 넣습니다.
5. 이 작은 예제에서는 모든 격자의 정답도 계산해 오차와 순위를 감사합니다.

[후보 CSV](/data/beam-surrogate/candidates.csv)의 `predicted_deflection_mm`은 모델 예측, `truth_deflection_mm`은 해석식 정답입니다. `b_mm`, `h_mm`, `mass_kg`, `feasible`, `relative_error_pct`도 함께 저장했습니다. 정답을 전부 계산한 마지막 단계는 평가용이며 학습으로 되돌아가지 않습니다. 비싼 시뮬레이션이라면 모든 후보의 정답을 구하는 대신 유망 후보와 별도 검증 표본에 계산 예산을 나눠야 할 것입니다.

지도는 **예측 처짐**을 색으로 표시합니다. 배경은 사이트의 중립색 계열이며, 색띠의 ‘좋음’ 쪽은 처짐이 작고 반대쪽은 큽니다. 밝은 테마에서는 밝음→어두움, 어두운 테마에서는 어두움→밝음 순으로 예측 처짐이 커집니다. 빗금은 질량 제한을 넘는 영역입니다. 색의 로그 척도는 작은 처짐의 차이도 읽을 수 있게 하지만, 같은 색 간격이 같은 mm 차이를 뜻하지는 않습니다. 선택 옆의 수치를 함께 확인하세요.

지도를 클릭하거나 슬라이더를 움직이면 저장된 가장 가까운 0.5 mm 격자점의 값과 형상이 함께 바뀝니다. 중간값을 보간하지 않습니다. 형상 그림은 설계 변수로 그린 **변형 전 직육면체**입니다. 처짐 곡선이나 변위장을 예측해 그린 그림이 아닙니다.

### 지도의 방향을 읽는 세 가지 방법

**먼저 폭을 고정하고 위로 이동해 보세요.** 높이를 키우면 처짐이 빠르게 줄어듭니다. 식에서 $\delta\propto h^{-3}$이기 때문입니다. 기준점에서 높이만 10% 늘린 22 mm라면 해석식 처짐은 약 24.9% 감소합니다. 하지만 질량도 10% 증가해 0.594 kg이 되므로 제한을 넘습니다. 성능이 좋아진 방향과 채택할 수 있는 방향은 다릅니다.

**다음으로 높이를 고정하고 오른쪽으로 이동해 보세요.** 폭을 10% 키우면 $\delta\propto b^{-1}$에 따라 처짐은 약 9.1% 감소합니다. 같은 비율의 치수 변화라면 이 하중에서는 높이 변화의 영향이 더 큽니다. 이는 해석식으로 확인한 방향이며, 실제 모델이 이런 경향을 얼마나 재현하는지는 예측 지도와 오차 지도를 함께 보며 판단합니다.

**마지막으로 같은 질량을 유지해 보세요.** 질량 제한 경계는 $bh=400\,\mathrm{mm}^2$입니다. 단면적 $A=bh$를 고정하면

$$
I=\frac{Ah^2}{12}, \qquad \delta\propto\frac{1}{Ah^2}.
$$

같은 재료량에서는 폭을 줄여 높이를 늘리는 쪽이 유리합니다. 위의 ‘기준 20 × 20’, ‘유망 후보 10 × 40’, ‘같은 질량 40 × 10’ 버튼을 차례로 눌러 보세요. 세 형상의 질량은 모두 0.540 kg인데, 해석식 처짐은 각각 약 0.4464, 0.1116, 1.7857 mm입니다. 같은 질량이어도 하중 방향에 따라 단면의 배치가 크게 작용합니다.

## 실제 형상 최적화로 확장하려면

이번 실험에서 한 일은 **설계 변수 → 스칼라 성능의 직접 예측**입니다. 각 위치의 변위·응력·압력 같은 전체 물리장을 학습하지 않았습니다. 물리장 모델이라면 형상 위의 각 위치에서 값을 예측하고, 그 장으로부터 최대 변위나 항력 같은 스칼라를 계산할 수 있겠지만, 그때는 국부 오차와 경계조건의 충족도도 검증해야 합니다.

또한 이번에는 고정된 모델로 격자를 평가한 **설계공간 탐색**을 수행했습니다. 모델이 제안한 형상을 해석하고, 새 정답으로 재학습한 뒤 다음 후보를 제안하는 **반복적인 최적화**는 수행하지 않았습니다. 두 과정은 연결할 수 있지만 같은 실험은 아닙니다.

더 비싼 문제로 옮길 때는 다음 순서가 도움이 됩니다.

1. 설계 변수가 유효한 형상을 만드는지 먼저 확인합니다. 복잡한 형상에서는 최소 두께, 자기 교차, 제조 제약을 포함해야 합니다.
2. 정답 생성기의 수렴성과 물리적 적합성을 확인합니다. 모델이 시뮬레이션을 잘 따라가도 시뮬레이션 자체의 오차는 남습니다.
3. 예측 오차뿐 아니라 후보 순위, 상위 후보의 선택 손실, 제약 경계 주변의 오차를 평가합니다. 여러 하중과 형상군을 다루게 되면 같은 계열이 학습·테스트에 섞이지 않도록 분리 기준도 재설계해야 합니다.
4. 학습 영역 밖이나 데이터가 드문 곳은 별도로 확인하고, 유망 후보를 원래 시뮬레이터 또는 실험으로 재평가합니다. 이번 커널 모델에는 보정된 불확실성 구간이 없습니다.
5. 필요하면 재평가한 자료를 추가해 모델을 갱신하고 다음 탐색을 진행합니다. 이 시점부터 반복적인 최적화 루프를 구성할 수 있습니다.

성능 지도의 가치는 ‘가장 좋은 색의 점’ 하나에만 있지 않습니다. 같은 질량에서 좁고 높은 단면이 왜 유리한지, 평균 오차가 작아도 어떤 영역은 다시 계산해야 하는지 설명할 수 있게 해 줍니다. 이번에는 두 개의 숫자로 정의한 작은 3D 형상이었지만, **형상 표현·정답 생성·예측 검증·후보 재평가를 연결하는 구조**는 더 복잡한 설계에서도 출발점이 됩니다.
