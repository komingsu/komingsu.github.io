에이전트가 엉뚱한 파일을 고치는 상황은 대부분 능력의 문제가 아닙니다. 사람이
새 팀원에게 30분 동안 말로 설명해 줄 것들 — 어디부터 읽어야 하는지, 무엇을
건드리면 안 되는지, 테스트는 어떻게 도는지 — 이 저장소 어디에도 적혀 있지 않기
때문입니다.

## 한 장으로 줄이기

`CLAUDE.md` 에 들어가야 할 것은 README에 이미 있는 내용이 아니라, README에
없어서 매번 다시 물어보게 되는 내용입니다.

- 빌드·테스트·린트를 실제로 돌리는 명령 한 줄씩
- 이 저장소만의 규칙 (예: "커밋 전에 `npm run check`")
- 손대면 안 되는 생성 파일의 경로
